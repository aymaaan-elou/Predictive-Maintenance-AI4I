# 🚗 Maintenance Prédictive pour Véhicules Connectés (IA4I)

## 📌 Contexte du Projet
Ce projet s'inscrit dans le cadre de l'Industrie 4.0 et de la transition vers les véhicules connectés. L'objectif est de développer un modèle de Machine Learning capable d'anticiper les défaillances mécaniques à partir de données de capteurs (température, couple, vitesse de rotation, usure), afin d'optimiser les interventions de maintenance et de réduire les coûts d'immobilisation.

## 🛠️ Technologies Utilisées
* **Langage :** Python
* **Data Science :** Pandas, Scikit-learn (Random Forest)
* **Interface Web :** Streamlit
* **Déploiement :** Streamlit Community Cloud
* **Versioning :** Git / GitHub

## ⚙️ Fonctionnalités
- **Modélisation :** Entraînement d'un classifieur (Random Forest) sur un dataset de capteurs industriels (AI4I 2020 Predictive Maintenance).
- **Interface Interactive :** Une application web développée avec Streamlit permettant de simuler des conditions de capteurs via des curseurs et d'obtenir une prédiction en temps réel sur le risque de panne.
